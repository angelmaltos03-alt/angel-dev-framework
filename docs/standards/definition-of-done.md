# ADF Definition of Done

- [ ] Requirements and acceptance criteria are identifiable.
- [ ] Implementation matches approved scope.
- [ ] Tests cover meaningful behavior and edge cases.
- [ ] Relevant automated checks were executed.
- [ ] Security and privacy implications were reviewed.
- [ ] Accessibility and responsive behavior were checked for user-facing changes.
- [ ] Documentation and examples were updated.
- [ ] Diff was reviewed for secrets, debug code, and unrelated changes.
- [ ] Actual results and known limitations are recorded.
- [ ] Required human review and approval were obtained.

Mark inapplicable items N/A with a reason. Never mark a check passed if it was not run.
